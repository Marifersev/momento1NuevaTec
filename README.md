Nombre del proyecto: SpendWise
Descripcion: SpendWise es una sencilla aplicación en Java y Python para registrar pequeños gastos diarios. Ayuda a los usuarios a controlar sus hábitos de gasto y a gestionar presupuestos de manera eficaz.
Que hace: Registrar gastos diarios, Categorizar gastos (comida, transporte, entretenimiento, etc.), Ver el gasto total a lo largo del tiempo
Tecnologias usadas: Python, Pandas
Requisito: requirements.txt
